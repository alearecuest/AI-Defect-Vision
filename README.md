# AI Defect Vision

Sistema de visión computacional para la inspección automatizada de componentes ópticos en entornos de Ensamblaje, Integración y Pruebas.

El script procesa fotomicrografías de filtros, lentes y espejos. Utiliza umbralización adaptativa y análisis morfológico para identificar, segmentar y medir el área de contaminación particulada (suciedad) o daños superficiales (puntadas/rayaduras), agilizando la certificación de hardware de vuelo.
